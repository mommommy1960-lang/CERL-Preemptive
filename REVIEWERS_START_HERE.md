# Reviewers Start Here

CERL-Preemptive is a prototype for consent validation, event logging, and auditable data-access decisions.

## Review focus

Verify token lifecycle, validator behavior, ledger integrity, API authentication, replay resistance, error handling, and deployment boundaries.

## Evidence boundary

The repository is a proof of concept. “Tamper-resistant,” “live,” or “secure” should be treated as hypotheses until independently tested in the intended deployment environment.
